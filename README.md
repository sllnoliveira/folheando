# 📚 Folheando

Aplicação:
https://folheando.onrender.com/


O Folheando é uma aplicação Full Stack para registrar leituras, avaliar livros e organizar uma biblioteca pessoal.

O projeto foi desenvolvido para praticar integração entre front-end, back-end e banco de dados.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- Python
- Flask
- Flask-CORS
- MySQL

## Funcionalidades

✅ Cadastro de usuários

✅ Login

✅ Biblioteca pública

✅ Cadastro de livros

✅ Avaliações

✅ Sistema de notas

✅ Modo visitante

## Objetivo

Este projeto foi desenvolvido para consolidar conhecimentos em desenvolvimento Full Stack, consumo de APIs e integração com banco de dados.
